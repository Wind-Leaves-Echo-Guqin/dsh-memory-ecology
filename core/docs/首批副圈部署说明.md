# 首批副圈 · 部署说明（dsh-eco-dev + quant-lab）

- 时间：2026-10-31
- 性质：**部署就绪载荷**。本轮机制交付不触生产数据根（插件切换涉及
  `cordis.patch.yml` 热重载 = 掐断活会话，红线单独排期）；本文档是
  机制上线时的唯一操作单。

## 1. 载荷（circles.json）

```json
{
  "schema_version": 1,
  "global_budget_chars": 600,
  "circles": [
    {
      "id": "dsh-eco-dev",
      "display_name": "dsh 记忆生态开发",
      "match": {
        "cwd_prefix": [
          "D:/work/dsh-memory-ecology",
          "C:/Users/qy160/dsh-memory-ecology",
          "C:/Users/qy160/qq-gateway",
          "C:/Users/qy160/eco-ops-live"
        ]
      },
      "budget_chars": 800,
      "catalog_limit": 20
    },
    {
      "id": "quant-lab",
      "display_name": "量化实验室",
      "match": {
        "cwd_prefix": [
          "D:/work/quant-lab"
        ]
      },
      "budget_chars": 600,
      "catalog_limit": 16
    }
  ]
}
```

说明：
- `schema_version`/字段以 `store.save_circles` 归一后的口径为准（本文件是
  `circles-write --file` 的输入，写入时会被校验 + 归一 + 备份）；
- 路由前缀一律正斜杠（核心按路径段边界比较，Windows 忽略大小写）；
- `attachable` 缺省 true（声明圈即授权 agent 挂载）；要"可写不可挂"就显式
  加 `"attachable": false`。

## 2. 部署步骤（机制上线日执行）

0. **先确认生产根**：本文所有 `--root` 都显式指向 `%LOCALAPPDATA%\hermes`
   （生产数据根，A2A 总览 §2 在案）。插件自身的默认根
   `%LOCALAPPDATA%\dsh\memory-eco` 从未启用——漏写 `--root` 会静默建一套
   平行空圈库（工具不报错）。执行前先跑
   `python -m memory_ecology --root %LOCALAPPDATA%\hermes health`
   确认根在、有 detail 条目。
1. **部署新核心 + 插件**（本轮 D 仓产物，走 `.bak-同步前-<ts>` + SHA256 校验；
   插件切换改 `cordis.patch.yml` 前先跑 `D:\work\dsh-ops-notes\live-sessions.ps1`
   确认没有活会话）。
2. 写圈（Guard 通道，自带校验/备份）：
   ```
   python -m memory_ecology --root %LOCALAPPDATA%\hermes circles-write --file docs/首批副圈-circles.json
   ```
3. 物化 + 验证：
   ```
   python -m memory_ecology --root %LOCALAPPDATA%\hermes materialize
   python -m memory_ecology --root %LOCALAPPDATA%\hermes circles
   ```
   预期：出现 `dsh-eco-dev` / `quant-lab` 两个声明圈（条目数 0 是正常态——
   历史记忆归圈等用户拍板，新记忆按 cwd 路由自动进圈）。
4. 会话验证（在 `D:\work\dsh-memory-ecology` 起一个 agent 会话）：
   - `memory_circle_list` → 看到 dsh-eco-dev（routed·已挂载）与 quant-lab（未挂载）；
   - `memory_circle_attach quant-lab` → 下轮尾段出现量化圈目录；
   - `memory_circle_detach quant-lab` → 尾段停止；
   - `ledger event` 表出现 `circle.attach` / `circle.detach` 落账。
5. `health` → `gate_lock`/`l1_reconcile` 字段在位，无新增 warn。

## 3. 回滚

- 圈配置：`configs/circles.json.bak-改圈前-<ts>` 原地回滚（写入口自带备份）；
- 插件/核心：还原 `.bak-同步前-<ts>` 副本 + 重启宿主；
- 已注入的圈尾段消息：随会话 compaction 自然滚出，无需清理。
